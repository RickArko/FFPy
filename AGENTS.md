# FFPy — Agent Guidance

## Commands
- **Setup**: `make bootstrap` (one-time, idempotent)
- **Run**: `make run` (Streamlit :8501), `make pickem-web PORT=8000` (FastAPI+Vue pick'em)
- **Test**: `make test` (pytest), `make check` (ruff + pytest — CI entry point)
- **Lint/Format**: `make lint` / `make fmt` (ruff, line-length=110, target py313, select E/F/W/I, ignore E501)
- **Coverage**: `make cov` (pytest + htmlcov/)
- **DB**: `make data` (real nflverse), `make data DATA_MODE=mock` (fast offline), `make db.load SEASON=2024`
- **Run single test**: `uv run pytest tests/test_scoring.py -x --tb=short`
- **Notebook**: `make notebook` (uses `--group analysis`; ipykernel pinned to <7 — v7 hangs with some jupyter_client combos)

## Architecture
- **Python 3.13+**, uv package manager with uv_build backend. Always use `uv run ...`.
- Entry points in `pyproject.toml [project.scripts]`: `ffpy` → `ffpy.app:main` (Streamlit), `ffpy-pickem-web` → `ffpy.pickem_web:main` (FastAPI), `ffpy-db` → `ffpy.cli:main` (SQLite CLI).
- SQLite at `~/.ffpy/ffpy.db`. Schema migrations in `src/ffpy/migrations/`, **append-only** — never edit a merged migration.
- `nflreadpy` installed from git: `nflverse/nflreadpy` (see `[tool.uv.sources]` in pyproject.toml).
- Source under `src/ffpy/`. The canonical module map is `AI-CONTEXT.md` (repo root) — auto-generated by `/ai-condense`, do not hand-edit.
- Historical planning docs live in `.ai/plans/` (moved from `docs/`).

## Conventions
- Do NOT `uv add` or modify `pyproject.toml` deps without asking. For experiments use `uv pip install` in the venv.
- `.env` values must NOT have trailing inline comments — python-dotenv includes them in the value.
- Streamlit: `@st.cache_data(ttl=Config.CACHE_TTL)` on data fetchers.
- Use `width` not deprecated `use_container_width` in Streamlit calls.
- CI: lint → test → docker build (PR/push to main); deploy to Fly.io on main push.
