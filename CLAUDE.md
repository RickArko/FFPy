# CLAUDE.md

Guidance for Claude Code (claude.ai/code) when working in this repo.

## Project Overview

FFPy is a Streamlit app + Python toolkit for fantasy football: weekly
projections, lineup optimization (PuLP/CBC ILP), pick'em backtesting,
ESPN league integration, and nflverse play-by-play ingestion. Data lives
in a local SQLite database; a FastAPI + Vue surface (`ffpy-pickem-web`)
exposes the pick'em strategy tester. Single-developer hobbyist project,
not multi-tenant.

## Key Commands

```bash
make bootstrap      # one-time: installs uv, deps, .env, DB schema
make run            # Streamlit app on http://localhost:8501
make dev            # Streamlit with auto-reload
make pickem-web PORT=8000          # FastAPI + Vue pick'em tester
make test           # pytest
make cov            # pytest + coverage
make lint / make fmt               # ruff
make check          # lint + test (CI entry point)
make db.migrate                    # apply SQL migrations
make db.load SEASON=2024           # load nflverse pbp for a season
uv run ffpy-db --help              # database CLI
```

## Architecture

Entry points are declared in `pyproject.toml [project.scripts]`:
`ffpy` → `ffpy.app:main` (Streamlit), `ffpy-pickem-web` → FastAPI app,
`ffpy-db` → SQLite CLI. Code lives under `src/ffpy/` (uv_build layout).

Core data flow: `nflreadpy` → `nflverse_loader.NFLVerseLoader` →
`database.FFPyDatabase` (SQLite) → `projections.HistoricalProjectionModel`
or `optimizer.LineupOptimizer` → Streamlit pages or pick'em web. ESPN /
SportsDataIO integrations under `src/ffpy/integrations/` provide live
projections with auto-fallback (ESPN free, SportsData paid). Schema is
versioned via `src/ffpy/migrations/001_*.sql` and `002_play_by_play_schema.sql`.

The condensed digest at `AI-CONTEXT.md` (repo root) is the canonical
map of every module, class, and method — read it first when orienting.
It is regenerated by `/ai-condense` and carries a signature header; do
not hand-edit.

## Conventions

- Python 3.13+. Build/package via `uv` (uv_build backend). Always invoke
  Python through `uv run …` so the right interpreter and lockfile are used.
- Lint + format with `ruff` (line-length=110, py313 target). `make fmt`
  before commits.
- Tests live in `tests/`, run with `pytest`. Add tests for any new
  scoring rule, optimizer constraint, or data parser.
- Database changes are migrations (`src/ffpy/migrations/NNN_*.sql`).
  Never hand-edit a merged migration — add a new one.
- `.env` values must NOT have trailing inline comments — python-dotenv
  keeps them as part of the value (caused a `ValueError` in
  `Config.NFL_SEASON` previously).
- Do NOT autonomously run `uv add` or modify `pyproject.toml` deps. For
  notebooks/experiments, use notebook-local installs or `uv pip install`
  in the venv. Confirm with the user before changing project deps.
- Streamlit cache: `@st.cache_data(ttl=Config.CACHE_TTL)` on data fetchers.
- Known bug surface: `integrations/espn.py::_parse_espn_data` references
  an undefined `projected_stats` (should be `extracted_stats`) — fix it
  if you touch that path.
